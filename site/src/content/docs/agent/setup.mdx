The agent is a chat assistant that lives in the Salesforce utility bar. The starter agent is called **Lumen**. Users ask it questions in plain language, and it uses the same tools to look things up and make changes in the org.

Here the AI model is called from Apex, so **you need an API key from a model provider**. Four come set up: OpenRouter, OpenAI, Azure OpenAI and Google AI Studio. If you have no preference, use [OpenRouter](https://openrouter.ai): one key gives you many models, including a free one. For your company's AI gateway, see [Connect a gateway](/ApexAgent/agent/gateway/).

[Install ApexAgent](../../start/install/) before you start.

## 1. Add your key

Pick your provider:

<Tabs syncKey="provider">
<TabItem label="OpenRouter">

Create a key on OpenRouter's [API keys page](https://openrouter.ai/keys) and copy it.

In Setup, go to **Named Credentials**, open the **External Credentials** tab, and open **ApexAgent OpenRouter Credential**. Under **Principals**, open the **Actions** menu at the end of the **Authorization** row and choose **Edit**. Add an authentication parameter:

- **Name:** `Authorization`
- **Value:** your OpenRouter API key, just the key. Do not put `Bearer` in front of it; ApexAgent adds that.

	src={openrouter}
	alt="The ApexAgent OpenRouter Credential external credential in Salesforce Setup, with a Principals section listing one principal named Authorization."
	caption="The Actions menu is at the right-hand end of the Authorization row, under Principals."
	focus={{ x: 86, y: 57, w: 13.5, h: 42 }}
/>

Lumen already uses OpenRouter, through **Gemini 3.8 Flash**.

</TabItem>
<TabItem label="OpenAI">

Create a key on OpenAI's [API keys page](https://platform.openai.com/api-keys) and copy it.

In Setup, go to **Named Credentials**, open the **External Credentials** tab, and open **ApexAgent OpenAI Credential**. Under **Principals**, open the **Actions** menu at the end of the **Authorization** row and choose **Edit**. Add an authentication parameter:

- **Name:** `Authorization`
- **Value:** your OpenAI API key, just the key. Do not put `Bearer` in front of it; ApexAgent adds that.

In step 3, set Lumen's LLM to **GPT-5.4 Nano (OpenAI)**.

</TabItem>
<TabItem label="Azure OpenAI">

Azure needs three things from your Azure OpenAI resource: its name, a key, and the name of a model deployment. You find the key under **Keys and Endpoint** on the resource in the Azure portal, and the deployment names under **Deployments** in Azure AI Foundry.

1. **Point the connection at your resource.** In Setup, go to **Named Credentials**, open **ApexAgent Azure OpenAI** and select **Edit**. Set **URL** to `https://<your-resource>.openai.azure.com` and save.
2. **Add the key.** On the **External Credentials** tab, open **ApexAgent Azure OpenAI Credential**. Under **Principals**, open the **Actions** menu at the end of the **Authorization** row and choose **Edit**. Add an authentication parameter named `Authorization` with your Azure key as the value. ApexAgent sends it in the `api-key` header that Azure expects.
3. **Name your deployment.** In the Setup Portal, open **LLMs**, open **GPT-5 Mini (Azure)** and set **Model API Name** to your deployment's name. It is `gpt-5-mini` by default, which only works if your deployment has that name.

In step 3, set Lumen's LLM to **GPT-5 Mini (Azure)**.

</TabItem>
<TabItem label="Google AI Studio">

Create a key in Google AI Studio's [API keys page](https://aistudio.google.com/apikey) and copy it.

In Setup, go to **Named Credentials**, open the **External Credentials** tab, and open **ApexAgent Google AI Studio Credential**. Under **Principals**, open the **Actions** menu at the end of the **Authorization** row and choose **Edit**. Add an authentication parameter:

- **Name:** `Authorization`
- **Value:** your Google AI Studio API key, just the key. Do not put `Bearer` in front of it; ApexAgent adds that.

In step 3, set Lumen's LLM to **Gemini 3.8 Flash (AI Studio)**.

</TabItem>
</Tabs>

## 2. Open the agent

From the App Launcher, open the **ApexAgent Setup Portal** app. Lumen is in the utility bar at the bottom of the screen, and also has a full-page **Lumen Agent** tab.

## 3. Pick a model

Setup creates five LLM records:

| LLM | Model | Provider |
| --- | --- | --- |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | OpenRouter |
| Free Model Router | `openrouter/free`, which routes to models OpenRouter offers at no cost | OpenRouter |
| Gemini 3.8 Flash (AI Studio) | `gemini-3.8-flash` | Google AI Studio |
| GPT-5 Mini (Azure) | `gpt-5-mini`, the name of your Azure deployment | Azure OpenAI |
| GPT-5.4 Nano (OpenAI) | `gpt-5.4-nano` | OpenAI |

<Screenshot
	src={agentRecord}
	alt="The Lumen agent record, with its LLM field set to Gemini 3.8 Flash."
	caption="The LLM field on the agent record decides which model Lumen uses."

Lumen starts on Gemini 3.8 Flash, through OpenRouter. To change it, open the **Agents** tab in the Setup Portal, open **Lumen** and set its **LLM** field to an LLM on the provider whose key you added. The two OpenRouter models both need your OpenRouter key, including the free one.

To use a model that isn't listed, see [Change the model](/ApexAgent/agent/models/). [Built-in providers](/ApexAgent/agent/providers/) explains what ApexAgent handles for each provider.
