You need two values from [Set up the MCP server](/ApexAgent/mcp/setup/): the **Endpoint URL** and the **client ID** (the External Client App's Consumer Key).

1. In Claude, open **Customize**, then **Connectors**. Select **Add**, then **Add custom connector**.

   <Screenshot
   	src={claudeAddMenu}
   	alt="The Connectors screen in Claude with the Add menu open, showing one item: Add custom connector."
   	caption="Add custom connector is the only item in the Add menu."
   	focus={{ x: 77.5, y: 28.6, w: 20.9, h: 16.3 }}
   />

2. Enter a name in the first field, such as `Salesforce`, and paste the Endpoint URL into the second field, **MCP server URL**. Select **Continue**.

   <Screenshot
   	src={claudeForm}
   	alt="The Add custom connector dialog in Claude, with Salesforce as the name and the ApexAgent endpoint URL in the MCP server URL field."
   	caption="The name is only a label in Claude. The MCP server URL is your Endpoint URL."
   />

3. Under **OAuth client**, choose **Use your own OAuth client**. A field labelled **OAuth client ID** appears under it; paste the Consumer Key there and leave the client secret empty. Claude preselects **Register automatically**, which Salesforce does not support, so change it.

   <Screenshot
   	src={claudeClientId}
   	alt="The OAuth client options in the Add custom connector dialog, with Use your own OAuth client selected and a client ID entered."
   	caption="Choose Use your own OAuth client, then paste the Consumer Key as the OAuth client ID."
   	focus={{ x: 3.3, y: 40.3, w: 92.9, h: 30.1 }}
   />

4. Scroll to the bottom of the dialog and select **Add**. Sign in with your Salesforce login if Claude asks. If you are already signed in to Salesforce in that browser, it connects straight away. Claude then lists the tools it found.

   <Screenshot
   	src={claudeConnected}
   	alt="The Salesforce connector in Claude after connecting, listing nine read-only tools such as Get Current User, Query Records and Search Records."
   	caption="Once connected, Claude lists the ApexAgent tools. Nine are read-only; the tenth, Upsert Records, is listed below them because it can change data."
   />

5. Ask Claude something about your org. The first time it wants to use a tool, it asks for permission. Choose **Allow once**, or **Always allow** to stop being asked for that tool.

   <Screenshot
   	src={claudeApproval}
   	alt="Claude asking for permission to use the Search Records tool from Salesforce, with Decline, Always allow and Allow once buttons."
   	caption="Claude shows which tool it wants to run, and with what input, before it runs it."
   />

Claude's callback URL, `https://claude.ai/api/mcp/auth_callback`, is already allowed in the External Client App.
