ApexAgent is a framework for building AI agents and MCP servers for Salesforce, in plain Apex. It comes with a working agent and MCP server.

Everything deploys into your org and runs with your users' own permissions. There is no middleware and no external server to host.

## No extra Salesforce licensing

ApexAgent uses only standard platform features: Apex, custom objects, Lightning Web Components and a Salesforce Site. It needs **no Agentforce license, no Einstein add-on and no Data Cloud**. It runs in Developer, Enterprise, Performance and Unlimited Edition orgs.

**The agent:** its running cost is the AI model. You pay your model provider directly for what you use, and ApexAgent adds nothing. The agent runs inside your org and calls the model from Apex; it doesn't connect to Salesforce as an outside AI client.

**The MCP server:** it brings no model of its own; the model belongs to the client that connects, such as Claude or ChatGPT. Each request uses one of your org's ordinary API requests today. Salesforce has [announced](https://help.salesforce.com/s/articleView?language=en_US&id=005360285&type=1) that calls from outside AI agents like these, over MCP or the API, will be billed in Flex Credits once it sets a rate, and that would apply to MCP calls here too.

To see how this differs from Agentforce and Salesforce's own MCP servers, read [ApexAgent agent vs Agentforce](/ApexAgent/start/compare/agent/) and [ApexAgent MCP server vs Salesforce Hosted MCP Servers](/ApexAgent/start/compare/mcp/). For how your data is protected, read [Security and data](/ApexAgent/operate/security/).

## Two things, one set of tools

ApexAgent gives you two things. They draw on the same set of tools, and you can use either one without the other.

[MCP](https://modelcontextprotocol.io) (Model Context Protocol) is an open standard that lets an AI app call tools hosted somewhere else. The agent works with any provider that accepts the OpenAI chat completions format, which most do. A connection to [OpenRouter](https://openrouter.ai), a service that gives you one API key for many AI models, comes preconfigured.

| | Agent | MCP server |
| --- | --- | --- |
| **What it is** | A chat assistant inside Salesforce, in the utility bar | An endpoint in your org that lets an outside AI app (Claude, ChatGPT, or any other MCP client) use Salesforce tools |
| **Where the AI model runs** | Called from Apex, at any OpenAI-compatible provider | In the client you connect. ApexAgent never calls a model. |
| **Extra Salesforce license** | **None** | **None** |
| **Who pays for the model** | You, through your account with the model provider | Whoever runs the client |
| **Needs a model provider API key** | **Yes**. OpenRouter comes preconfigured, or use your own | **No** |
| **Needs an External Client App**, Salesforce's newer form of a Connected App | No | **Yes**. The deploy creates it |
| **Users sign in with** | Nothing extra; they are already in Salesforce | Their own Salesforce login, from the client |

## What's included

- **[Ten built-in tools](../../tools/built-in/)** for finding objects, reading records, running queries and saving changes.
- **ApexAgent Setup Portal**: a Lightning app for managing LLMs, agents, topics, instructions, tools and MCP servers.
- **Logs** of every conversation, message, tool call and error.
- **Reports and dashboards** for agent and MCP activity.
- **A setup script** that creates a working starter configuration, so there is something to use right after install.
